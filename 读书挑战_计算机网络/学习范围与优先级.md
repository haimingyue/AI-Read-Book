# 计算机网络学习范围与优先级

以教材六章为范围，主线是“数据如何封装、通过链路、跨网络转发、可靠送达并支持应用”。用具体分组旅程串联分层知识，不能把端口、MAC地址、IP地址混成同一种地址。

| 优先顺序 | 内容 | 必须保留的能力 |
|---|---|---|
| 先修 | 单位换算、二进制前缀、分层、发送与传播、基本拓扑 | 先理解量的含义，能画出数据经过的设备与链路 |
| 第一条计算主线 | 性能指标、信道容量、ARQ窗口、介质访问 | 画时间线，识别假设，再推公式和计算 |
| 第二条计算主线 | IPv4、子网、CIDR、转发、分片与路由 | 地址按位判断，按最长前缀选路，追踪逐跳变化 |
| 第三条计算主线 | TCP序号、ACK、连接、流量与拥塞控制 | 区分字节序号、接收能力和网络拥塞，按事件更新状态 |
| 跨层整合 | DNS、HTTP、FTP、邮件及整段通信过程 | 说明每一步用哪层协议、访问谁、是否需要额外RTT |
| 按诊断控制深度 | 介质细节、多播/移动IP、复杂报文与特殊情形 | 先掌握教材基本规则；暂缓时明确记录覆盖缺口 |

## 练题路线

每次从[知识地图](核心知识地图.md)选一个能力块，阅读对应教材小节。完全不会时先示范，然后选一题基本应用和一题过程解释或综合小问，最后安排间隔新题。题目来自[分节题库](真题/README.md)，一天不要求刷完整节。

每道计算题写清：求什么 → 已知量和单位 → 模型/条件 → 拓扑、时间线或状态表 → 公式与代入 → 量纲、数量级和边界检查。背出公式、说“懂了”和独立解题分别记录。

## 复盘方式

链路层、网络层和TCP各留诊断/机动时段。独立测验中单选与综合分开计分，记录是否见过、提示和实际时长；得分率按实际所测网络部分满分计算。具体分数目标尚未约定，不从某些题型的正确率推断全科达标。

教材题量仅作为材料分布参考，不能直接当作未来命题概率。优先级还需根据用户首次作答、先修缺口与时间预算调整。
