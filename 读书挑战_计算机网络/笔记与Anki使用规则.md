# 计算机网络笔记与Anki使用规则

沿用少而精原则，每次通常新增0～3张，不凑数。先理解，再根据真实遗忘或混淆制卡；完整计算和综合时序仍用整题检验。

| 内容 | 记录方式 |
|---|---|
| 易混术语、协议分层、字段含义 | 短辨析，带适用模型和条件 |
| 公式与计算决策 | 问“何时用、量是什么、单位是什么”，不要只背字母串 |
| 分组旅程、协议交互、窗口变化 | 一张拓扑/时间线/状态表，配关键因果说明 |
| 完整计算题 | 原件、首次表现、关键错误和纠正依据，继续做完整题 |

一张卡只检验一个主要目标。协议版本、ACK含义、序号空间或假设不明确时先核对，不把特例做成通则。已有卡能覆盖时优先修订；旧Anki由用户自行复习。
