## 文件使用

- 每章下按知识小节保存，`题目/`里共193张单题图片；跨页题按原阅读顺序拼接。
- 各有题小节的`解析/README.md`链接整节教材解析原页，按题型及教材题号查找。解析没有逐题裁图。
- `PDF原页/`保留173张144 dpi完整来源图片，供核对选项、图表、代码、脚注和裁剪边界。
- [提取记录](提取记录.json)保存来源SHA-256、题目编号、页码、裁剪坐标、拼接位置和图片SHA-256。
- [核对记录](核对记录.md)说明核对范围、特殊题干和材料边界。

先做单题，再打开解析。1.4和1.5的题目来自教材1.6共用题区，已经按实际考点归类；3.2的2017年综合题18附有共享题干。整理资料不增加学习次数、掌握记录或调整其他科目排程。
