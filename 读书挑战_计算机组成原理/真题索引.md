# 真题原件索引

核对日期：2026-09-29。本文件记录本地材料的位置和核对程度，不记录掌握程度，也不提供标准答案。

## 使用规则

1. 每次选题、转述题干、判分之前，重新打开原截图，核对年份、题干、图表、单位、选项和所有小问；本索引不能替代原件。
2. 以下“截图号”指图片上的印刷题号，可能是复习书重新编排的题号。**没有统考原卷依据时，不把它写成官方 Q 题号。**稳定引用采用“年份/截图号/目录与文件名”，例如 `2021/截图33/Chapter3_5/03.jpg`。
3. 截图中的“统考真题”字样是材料自身的来源标注；本次未另行核对官方原卷。旧记录中的“2020 Q37”等简称只能作为历史别名，不能作为题号已核实的证据。
4. **找不到所需题目原件，或截图缺少必要条件、图表、选项、跨页续文时，必须请用户截图并保存到对应的 `真题/` 文件夹，核对后再出该题。不能凭记忆、年份或答案补造题干。**请求时写清需要的章节、题目和缺失部分；不能以“计划到了这题”为由跳过核对。
5. 原件未附答案或解析时，只能把解答标为“根据题干推导”，不能声称“已核对标准答案”。若题目有特殊约定、题干歧义或无法独立核实的解析依赖，先请用户补相应解析页，再作确定判分。
6. 自编例题或变式可以用于教学，但必须显式标注“自编练习”或“真题变式”，与原题分开记录；不能替代缺失的真题原件，也不能计入真题首次正确率或未见限时卷成绩。
