## 真题原件是出题依据

**每次出真题前，必须打开对应题目原件，核对年份、题号类型、题干、单位和选项。找不到对应真题或原件不完整时，必须请用户截图并保存到 `真题/` 对应章节文件夹；核对完整截图后再做。不能凭记忆补题干、猜选项或把自编题当真题。**

题目解析不是现成可见时，可以明确给出“独立推导、未与标准解析核对”；题目依赖缺失图表或特殊解析说明时，先补原件。教材题号、截图印刷号、统考原卷题号分别记录，不能互相代替。自编题仅用于明确卡点的钻练，必须标“自编练习”。

## 每次辅导如何结束

AI 根据实际作答更新日志、错题状态、当前快照；变更排程时更新唯一日历。记录提示程度、原件路径和下一次验证，不把讲解后复述算作首次独立正确。尚未结束的学习可以记“进行中”。整理文件不计新增学习次数。

旧卡由用户在 Anki 中自行复习；需要新卡时按规则筛选，允许 0 张。只修改本地 CSV 不等于同步了 Anki。网页阅读记录“已读”也不代表知识已经掌握。
