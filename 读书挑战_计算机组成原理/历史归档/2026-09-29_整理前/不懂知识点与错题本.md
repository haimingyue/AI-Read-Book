### 【考点】2.2 定点乘法·原码一位乘的"整体右移"（**P/Q 左右换位**）（新错，2026-09-23）
- **日期**：2026-09-23
- **来源**：当日讲义钻练 **$7\times5$**（4 位无符号，$M=$`0111`、$Q=$`0101`，正确结果 `0010 0011`=35）
- **现象**：**第 1、2 轮独立全对**（看 Q 最低位 → 加/不加 → 整体右移，全对：`0000 0101`→`0011 1010`→`0001 1101`）；**第 3 轮加法也对**（`0001+0111`=`1000`）；**错在右移那一步**——用户自述"**该更新 P，我却用 Q 顶了 P 的位置，还把新值放到后边**"→ 位串**左右换位**成 `0001 1000`（正确 **`0100 0110`**）。
- **根因**：①**概念没缺**（循环三步已会，前两轮是自己做对的）→ 属"**空间布局**"层的手误，不是理解缺口；②缺"**$(P,Q)$ 是一个 $2n$ 位串、P 恒在左（高 n 位）、Q 恒在右（低 n 位）**"的防呆意识，不知道右移时 **P 的最低位要跨"中线"进 Q 的最高位、而 P 自己不许挪到右边**；③连带隐患：看到 $P=$`1000`（最高位是 1）一度以为"**装不下/要丢**"——**是"进位≠溢出"的复发苗头**（`0001+0111`=`1000` 没加出第 5 位，不用丢）。
- **钻练**：立**防呆三句** + 8 格位图（见下）→ 用户随即**独立走通第 4 轮**（Q 最低位=0 ✅ / 不加 ✅ / 右移 `0010 0011` ✅ / 结果 **35** ✅）→ **$7\times5$ 全程 4 轮通关**（第 1、2 轮原本就对，第 3 轮换位错已纠正）。
- **状态**：⏳ **布局问题当场解决，待 +1 天（09-24）用新题复验**（$5\times3$，4 位无符号，正确 `0000 1111`=15）

> ### 🔑 原码一位乘 · 防呆三句（贴在脑门上）
> 1. **P 在左，Q 在右，位置永不换**（P = 高 n 位，Q = 低 n 位）
> 2. **右移 = 左端补 0、右端丢一位**（逻辑右移，不是算术右移）
> 3. **P 的最低位跨中线 → 进 Q 的最高位**（只跨这一条线，别的不动）
>
> ```
>      位:  7  6  5  4 │ 3  2  1  0
>           ┌──┬──┬──┬──┼──┬──┬──┬──┐
>  加完:   │ 1│ 0│ 0│ 0│ 1│ 1│ 0│ 1│   ← P=1000 │ Q=1101
>           └──┴──┴──┴──┼──┴──┴──┴──┘
>                      ↑ 中线(跨这里)
>           ┌──┬──┬──┬──┼──┬──┬──┬──┐
>  右移:   │ 0│ 1│ 0│ 0│ 0│ 1│ 1│ 0│   ← P=0100 │ Q=0110 ✅
>           └──┴──┴──┴──┼──┴──┴──┴──┘
>            ↑                             ↑
>        左端补 0                  右端那位丢掉
> ```
> ⚠️ 那个 `1000` 里的 1 **没丢**：它只是从 P 的最高位挪到 P 的次高位。

### 【考点】2.2 定点数运算·"进位≠溢出"（梯队🥇 单选+综合 2011,2020）（最重要，待验证）
- **日期**：2026-09-01

- **钻练**：8 道钻练全对（加减/溢出/移位）；口诀已建立——**正+正得负=溢出、负+负得正=溢出、正+负永不溢出；进位直接丢**。
- **状态**：⏳ 概念已懂、判断刚纠正，**待再次验证**（下次复习：Q30、Q32、Q33 用"看结果符号是否反常"再判一遍，确认不再被进位误导）
