## 1.1 计算机发展历程
- **硬件发展**：电子管 → 晶体管 → 中小规模集成电路 → 大规模/超大规模集成电路（四代）。按"元件"划分。
- **软件发展**：机器语言 → 汇编语言 → 高级语言（结构化/面向对象）。
- 考点：记住分代**依据是电子元器件**。

## 1.2 计算机系统层次结构（本章核心）

### 1.2.1 系统的组成
- 计算机系统 = **硬件 + 软件**。
- 软件分：**系统软件**（操作系统、编译程序、数据库管理系统、驱动程序……）与 **应用软件**。
- 通常说的"计算机组成原理"偏**硬件**；"操作系统"对应系统软件，两者在 408 是两门。

### 1.2.2 计算机硬件（五大部件——必背）
「**运算器、控制器、存储器、输入设备、输出设备**」
- **运算器 + 控制器 = CPU（中央处理器）**。
- CPU + 主存 = **主机**。
- **冯·诺依曼结构**要点（考试高频）：
  1. 计算**程序和数据都用二进制**表示。
  2. **存储程序**：程序和数据都存放在存储器中，机器按顺序从存储器取指令执行——"存储程序概念"。
  3. 硬件由**五大部件**组成。
  4. 指令由**操作码+地址码**组成。
  5. 以运算器为中心。（注：现代机器已改为以存储器为中心，早期冯氏以运算器为中心。）

### 1.2.3 计算机软件
- 指令 = 机器能直接"看得懂"的命令。
- 编译程序：高级语言 → 汇编/机器语言；汇编程序：汇编 → 机器语言；解释程序：逐句翻译执行。
- 三级语言：机器语言（唯一可直接执行）、汇编语言、高级语言。

### 1.2.4 计算机系统的层次结构
- 从高到低：应用软件层 → 系统软件层（含 OS）→ 机器语言层（微程序/硬布线）……
- 便于理解：**高层"翻译/解释"成低层**。

### 1.2.5 计算机系统的工作原理
- **指令周期**的基本流程：**取指令 → 分析指令 → 执行指令**。
- "程序"是若干指令的集合，处理器不断"取指—译码—执行"循环。
- 每秒能取指/执行多少次，由主频等因素决定（见下节）。

## 1.3 计算机的性能指标
### 1.3.1 主要性能指标（常考计算）
- **主频 f** = 时钟频率（Hz）。**时钟周期 T = 1/f**。
- **CPI** = 执行一条指令平均需要的时钟周期数。**CPU 时间 = 指令条数 × CPI × 时钟周期** = 指令数 × CPI / 主频。
- **MIPS** = 每秒执行多少百万条指令 = 主频(Hz) / (CPI × 10^6)。
- **FLOPS**：每秒浮点运算次数。
- **字长**：
  - **机器字长** = CPU 一次能处理的二进制位数（通常=通用寄存器宽度），整数和位数。
  - **存储字长** = 一个存储单元（字）可存二进制位数。
  - **指令字长** = 一条指令的位数。
  - 这三者**常考易混**，记住"谁跟谁对应"。
- 响应时间 vs 吞吐量（吞吐率）。

### 1.3.2 几个专业术语
- 主存容量、运算速度（基本字长、主频、MIPS、FLOPS）、加速比。
- **存储周期/存取时间**（留给第3章细分）。

## 1.5 常见问题与易混淆知识点
- **机器字长 ≠ 存储字长 ≠ 指令字长**。
- **存储程序** 与 **存储程序控制** 的区别：前者指"程序存放在内存中"；后者指"用程序控制机器自动执行"。
- **以运算器为中心 vs 以存储器为中心**：冯氏早期以运算器为中心（数据要经运算器转存），现代以存储器为中心。

## 今日自测（闭书回答，再对答案）
1. 冯·诺依曼计算机由哪五大部件组成？哪两个合成 CPU？
2. "存储程序"概念的核心含义是什么？
3. 机器字长、存储字长、指令字长分别指什么？
4. 已知主频 2GHz、CPI=4、指令数 4×10^8，求 CPU 时间。
5. 解释编译程序与解释程序的区别。

<details><summary>参考答案</summary>

1. 运算器、控制器、存储器、输入设备、输出设备；运算器+控制器=CPU。
2. 程序和数据都放在存储器中，机器按地址顺序自动从存储器取指令、分析、执行。
3. 机器字长=CPU一次能处理的位数；存储字长=一存储单元的位数；指令字长=一条指令的位数。
4. CPU时间=指令数×CPI×时钟周期 = 4×10^8 × 4 × (1/2×10^9) = 0.8 秒。
5. 编译程序把整个高级语言源程序一次性"翻译"成机器/汇编语言再执行；解释程序逐句边翻译边执行。

</details>

## 易错抢记
- 分代依据 = **元件**。
- 五大部件 + CPU = 运算器+控制器 + 主机 = CPU+主存。
- CPI 越小越好；主频越高越好（同一体系结构下）。
