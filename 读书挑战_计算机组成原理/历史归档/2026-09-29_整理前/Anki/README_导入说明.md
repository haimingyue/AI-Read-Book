## 如何导入 Anki
1. 打开 Anki → 文件 → **导入**（Import）。
2. 选择 `计组_闪卡_第1章.csv`。
3. 在导入设置里：
   - 字段分隔符：**逗号（,）**
   - **第一行含字段名**：勾选（跳过表头"正面,背面"）
   - 笔记类型：**基础（Basic）**
   - 牌组：新建 `计组_408` 或放入默认牌组
4. 预览无误后导入。
（若用 .txt：字段分隔符选 Tab，无表头。）
