# 408 组成原理 · 考频分析与优先级（基于考点1/考点2 手写考频表）

> 来源：用户整理的 2026 考研考频笔记（按年份统计 单选 / 综合 出现情况）。年份末尾代表"哪些年考过"。
> 用途：为"30 天拿 70% 分"确定优先级——**高频+综合** 是必得分，中等低频只求单选会做。

---

## 一、各章节考频一览

### 第1章 计算机系统概述（★ 重点：1.1发展史 + 1.3性能指标）
- 1.1~1.3 选择：10,11,12,13,14,17,20,21,22,23
- 本章**只出单选**，1~2 题，性价比高（花少量时间拿稳）。

### 第2章 数据的表示和运算（单选+综合，**高收益**）
- **2.1 数制与编码/补码**：选择 12,15,16,18,19,20,24
- **2.2 运算方法与电路**：选择 09,10,13,14,18,20,23,24 ；★ 综合 2011, 2020
- **2.3 浮点数表示与运算 (IEEE754)**：选择 **09-16,18,20,21,22,23,24（几乎年年考）** ；综合 2017
- 结论：**2.3 浮点是单选最高频 + 2.2 出过综合**，必须吃透。（补码/浮点 是"钻练"第一区）

### 第3章 存储系统（单选+综合，**全卷最重要**）
- 3.2 主存：选择 2010,2012,2014,15,17,18,22
- 3.3 主存与CPU连接：选择 09,10,11,16,21,23
- 3.4 外部存储：选择 13,15,19
- **3.5 Cache**：选择 09,12,16,17,21,22 ；★ 综合 **2010, 2013, 2020**
- **3.6 虚拟存储器**：选择 10,13,15,19,20,22,24 ；★ 综合 **2011, 2016, 2018, 2021, 2023（综合考得最密）**
- 结论：**3.5 Cache + 3.6 虚存是两道综合题的常客**，是"70 分"的命脉。

### 第4章 指令系统（单选为主，偶有综合）
- 4.x 选择：多年考（寻址方式、指令格式、扩展操作码）
- 结论：**4.2 寻址方式** 为重点；4.4 CISC/RISC 低频。

### 第5章 中央处理器（单选+综合，**全卷最难**）
- 5.1/5.2 基本结构与指令周期：选择
- **5.3 数据通路**：选择高频，且是综合题/大题常客（**难**）
- 5.4 控制器（硬布线/微程序）：选择
- 5.5 异常与中断：选择
- **5.6 指令流水线**：选择 **极高频** + 综合
- 5.7 多处理器：低频
- 结论：**5.3 数据通路 + 5.6 流水线** 是本章重点，也是难点。

### 第6章 总线（单选）
- 6.1 选择：09,10,11,12,13,14,15,19,20,21,23
- 结论：**只出单选**，性价比高，一次过。

### 第7章 输入/输出系统（单选+综合）
- 7.1/7.2 基本概念与 I/O 接口：选择
- **7.3 I/O方式（程序查询/中断/DMA）**：选择高频 + 综合
- 结论：**7.3 中断+DMA** 是重点。

## 二、为 70% 分的优先级排序（必得分 → 保底分）

### 🥇 第一梯队（高频 + 出过综合题 = 必得分，投入最重）
1. **3.6 虚拟存储器** —— 综合题最密集（2011,16,18,21,23）
2. **3.5 Cache** —— 单选 + 综合（2010,13,20）
3. **2.3 浮点数 IEEE754** —— 单选几乎年年 + 2017 综合
4. **5.6 指令流水线** —— 单选极高频 + 综合
5. **2.2 定点数运算** —— 单选 + 综合（2011,2020）

### 🥈 第二梯队（高频单选，分值稳定，要稳拿）
6. **2.1 数制/补码/编码**
7. **3.2 / 3.3 主存与 CPU 连接**
8. **5.3 数据通路**（难，综合常客）
9. **4.2 寻址方式**（指令系统）
10. **7.3 I/O方式（中断/DMA）**

### 🥉 第三梯队（中低频，会做单选即可，别沉迷）
11. 1.x 概述/性能指标（1~2 单选）
12. 6.x 总线（单选）
13. 3.4 外部存储（偶考）
14. 5.5 异常中断 / 5.7 多处理器 / 4.4 CISC-RISC / 7.1、7.2

## 三、对计划的直接影响（拿 70% 的打法）

1. **时间权重重排**：把最多的时间给 **第2章(尤其是2.3浮点) + 第3章(3.5 Cache、3.6虚存) + 第5章(5.6流水线)**。
2. **真题更早、更聚焦**：从第 2 周起，按**第一梯队**的考点做 408 真题选择+综合，别等全书读完。
3. **综合题保 6 成**集中练 6 个高频综合点：**虚存、Cache、浮点/定点、流水线、数据通路、I/O**。
4. **第三梯队果断"压缩"**：1、6 章用零碎时间过一遍拿单选分，不投入大块时间。

> 一句话：**70 分 = 把第一梯队练到"综合题也不丢分" + 二梯队单选稳拿 + 三梯队顺手拿。**
