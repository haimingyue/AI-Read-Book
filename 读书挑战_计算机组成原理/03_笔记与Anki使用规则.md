# 笔记与 Anki 使用规则（当前生效）

> 2026-09-29 修订。总辅导规则见 [辅导规则.md](辅导规则.md)。按实际遗忘点和练习需要选择工具，不把“事实、概念、过程”当成互斥的工具禁令。

## 1. 什么适合制卡

| 学习需要 | 可以采用的卡片或记录 | 如何验证效果 |
|---|---|---|
| 事实、定义、必要常量 | 一问一答的短卡，写清适用范围 | 闭卷答出，能在题目中认出 |
| 已理解但易混的概念 | 短辨析、原因或反例卡；必要时配一张小图 | 能解释关键区别，并在新例子中判断 |
| 计算中的关键决策 | 提问“此时选哪个量/规则、为什么”，或保留简短步骤图 | 回到完整题独立计算 |
| 完整运算、地址划分或代码分析 | 完整练习、错题记录和必要的示范步骤 | 无提示做题；之后间隔复验 |

完整长计算不宜塞进一张大卡。卡片可支持记忆关键步骤和条件，不能替代实际运算。笔记可以保留准确公式、条件和示范步骤；注明来源，再用自己的话解释或应用，不要求把标准定义强行改写。

## 2. 每次制卡前的筛选

1. **先理解**：这个点是否已经讲清？若仍完全不懂，先讲解和练习，不把陌生答案直接交给用户背。
2. **确实需要**：是否重要、易忘或已反复混淆？已有旧卡能覆盖时，优先修订旧卡，避免重复。
3. **能明确评分**：一张卡只检验一个主要目标；问题包含必要的位宽、类型、范围等条件，答案短且可判断对错，避免“这个是什么”式含糊指代。
4. **能用于题目**：概念卡可以问区别、原因或一个简短例子的判断。计算决策卡可以问“直接映射中，已知内存块号后，用什么量求 Cache 行号和 Tag？”；完整地址计算继续练习。

**每次学习通常新增 0～3 张，不凑数。** 没有合适内容可以不生成；有更多候选时先选最重要的，其余待后续练习验证。新卡数量也要考虑用户实际复习负担。

## 3. 制作与导入

- 制卡时先检查 `Anki/` 现有卡片，并核对 [导入说明](Anki/README_导入说明.md)；沿用已有 CSV 字段、编码与命名约定，避免导入成错列或重复卡。
- 对 CSV 内容逐行核对知识条件、正反面和重复项，再提供文件链接。新文件标记“待导入”；没有用户确认或实际导入证据，不改成“已导入”。
- 发现旧卡知识错误，修正源文件并告诉用户具体改哪张；若已导入，说明还需要在 Anki 中更新，不能把修改本地 CSV 当成已同步。
- **旧卡由用户自行在 Anki 中复习。** 除非用户明确要求辅导旧卡，不在对话里代刷、不重新问一轮旧卡。需要检验应用能力时，安排正常练习并写明检验目标。

## 4. 笔记和错题保持精简

- 只记录能帮助下一次学习的内容：易混条件、一张关系图、关键步骤、真实错误与修正依据。
- 错题的首次答案、提示程度、复验状态写入 [不懂知识点与错题本.md](不懂知识点与错题本.md)，不重复制作整套长笔记。
- 整理工具和做题都服务于理解、记忆及应用；当工具不再解决具体问题时就停止整理，进入下一次必要练习。
