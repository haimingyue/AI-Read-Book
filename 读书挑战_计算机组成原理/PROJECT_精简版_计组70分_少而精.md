# 学习范围与优先级

> 保留旧文件名以兼容链接。目标统一为“计组部分得分率 ≥70%”；按本项目 45 分口径为 31.5 分，不是计组考 70 分。当前进度在[状态文件](状态与下一步.md)，日期在[唯一排程](学习排程.md)。

## 怎样安排有限时间

真题确定需要练的能力；优先级结合题目分布、先修知识、自己的首次作答与剩余时间。历史考频只提供参考，不能保证未来分值。新模块先检查基础；允许阅读教材对应段落和短讲解。

| 优先级 | 内容与目标 | 前置知识/安排 |
|---|---|---|
| 当前主线 | Cache：映射、替换、写策略、地址划分、命中率与综合 | 补齐按字节/按字寻址、容量单位、数据区与元数据区别 |
| 后续主线 | 虚存：页/页框、页表、TLB、地址翻译及与 Cache 配合 | 承接 Cache 地址分段；需要的主存知识嵌入学习 |
| 后续主线 | 流水线：阶段、时空图、相关/冒险、性能计算 | 先补取指/译码/执行/访存/写回、寄存器与数据通路基础，不能把这些前提完全删掉 |
| 持续复验 | 数制、补码、CF/OF、乘法、IEEE754、性能 | 已学不等于稳定；每天挑 1～2 个错点检验 |
| 依诊断安排 | 主存与 CPU 连接、寻址、I/O、总线及其他覆盖缺口 | 结合独立测验和综合题依赖选择，不宣称未学部分一定无分 |
| 暂缓深入 | Booth 大表、复杂异常、多处理器等尚无具体主线需要的深入内容 | 暂缓是时间决策，记录未覆盖；若真题明确依赖则调整 |

## 怎样检验目标

- 最终计组得分率 = 该部分实得分 ÷ 该部分满分；以实际试卷和评分标准为准。
- 单选与综合分别计分，可设置单选90%、综合60%的训练目标，但高频子集的正确率不能替代整卷成绩。11道等分单选对9道是81.8%，对10道约90.9%。
- 首次无提示、提示后完成、间隔复验、换题通过分别记录。样本少时报告具体题目，不外推预计考分。
- 保留3次计划中的限时计组测验。10-26 验收至少需要其中2次来源可核对的有效成绩及错题复验证据；这不是删掉第3次测验的理由。使用未练过的题；若题目已见或经提示，明确说明对评估的限制。
- 尚未达到70%时如实报告缺口，列出下一阶段策略，不因到期自动宣布结课达标。
