每天计组约1小时沿用10-14约定；2026-10-19按用户授权顺延未执行任务2天，阶段验收移至10-28，主要剩余范围仍争取11月中下旬完成，具体日历仅维护在唯一排程。

## 怎样安排有限时间

真题确定需要练的能力；优先级结合题目分布、先修知识、自己的首次作答与剩余时间。历史考频只提供参考，不能保证未来分值。新模块先检查基础；允许阅读教材对应段落和短讲解。

| 优先级 | 内容与目标 | 前置知识/安排 |
|---|---|---|
| 已学待综合 | Cache：映射、替换、写策略、地址划分、命中率与综合 | 补齐按字节/按字寻址、容量单位、数据区与元数据区别 |
| 已学待综合 | 虚存：页/页框、页表、TLB、地址翻译及与 Cache 配合 | 承接 Cache 地址分段；需要的主存知识嵌入学习 |
| 已学并有补缺 | 流水线：阶段、时空图、相关/冒险、性能计算 | 先补取指/译码/执行/访存/写回、寄存器与数据通路基础，不能把这些前提完全删掉 |
| 持续复验 | 数制、补码、CF/OF、乘法、IEEE754、性能 | 已学不等于稳定；每天挑 1～2 个错点检验 |
| 后续主要范围 | 主存与CPU连接、指令系统与寻址、CPU数据通路与控制器、总线、I/O（查询、中断、DMA） | 阶段验收诊断后按唯一日历推进；先核查已有基础，再教缺口并做代表题，不把无记录断言为完全未学 |
| 暂缓深入 | Booth 大表、复杂异常、多处理器等尚无具体主线需要的深入内容 | 暂缓是时间决策，记录未覆盖；若真题明确依赖则调整 |

## 怎样检验目标

- 最终计组得分率 = 该部分实得分 ÷ 该部分满分；以实际试卷和评分标准为准。
- 单选与综合分别计分，可设置单选90%、综合60%的训练目标，但高频子集的正确率不能替代整卷成绩。11道等分单选对9道是81.8%，对10道约90.9%。
- 首次无提示、提示后完成、间隔复验、换题通过分别记录。样本少时报告具体题目，不外推预计考分。
- 保留3次计划中的限时计组测验。阶段验收至少需要其中2次来源可核对的有效成绩及错题复验证据；这不是删掉第3次测验的理由。使用未练过的题；若题目已见或经提示，明确说明对评估的限制。
- 尚未达到70%时如实报告缺口，列出下一阶段策略，不因到期自动宣布结课达标。

## 主要范围完成口径

已讲清约定范围并完成代表性基础应用，才能登记该部分教学与基础练习完成；独立、间隔和迁移证据继续分别记录。11月范围完成不自动等于70%达标，也不代表整套408覆盖。Booth大表、复杂异常与多处理器深入内容仍暂缓；教材或真题出现未列项目时先明确归属与优先级，不默认为已覆盖。
