## 新卡导入

1. 只选已经理解、尚无重复、确需间隔提取的卡；完整计算仍以换题练习为主。
2. 文件为 UTF-8、逗号分隔、两列，映射到 Basic/基础笔记的正面与背面。必须先写 `#separator:Comma`，再写 `#html:false` 和 `#columns:正面,背面`（各占一行）。列名按此前已声明的分隔符解析；不能仅依赖导入界面随后猜测逗号。这些说明行适用于Anki 2.1.54及以后，不是卡片。
3. 关闭“允许 HTML”等 HTML 解释选项；卡片采用纯文本，`<`、`>` 等数学符号应保持原样。不同版本界面名称可能不同。
4. 查看导入预览，确认中文、题面、完整背面、两列对应和预计新增数。若使用不支持 `#columns` 的旧版本，导入临时副本时去掉全部以 `#` 开头的说明行，并手动选择逗号分隔。
5. 确認没有与现有知识点重复再导入；随后按 Anki 安排复习。新增数量由实际需求和复习负担决定，不必为了凑数量而制卡。

## 更新已存在的卡

本次保留原有题面，主要修背面。Anki 文本导入以“第一字段相同、笔记类型相同”为基础匹配已有笔记；匹配范围若同时限制牌组，还须选对牌组。选择更新已有笔记可保留原来的复习记录。[Anki 官方导入说明](https://docs.ankiweb.net/importing/text-files.html#duplicates-and-updating)

**优先在 Anki 浏览器找到原卡，直接把背面改成对应 CSV 的新版内容。** 这样可逐张修复并确认卡确实存在。

若使用 CSV 批量更新：先确认题面与笔记类型匹配，选择更新已有笔记，核对预览的新增/更新数量。本次仅修旧卡时，预计新增数应为 0；出现新增先检查未导入的历史卡或题面差异，不能靠反复全量导入解决。两个旧文件的引号格式曾损坏，可能造成实际题面与文件原意不一致，按修订说明中的映射手动处理。

同一知识点但题面不同的卡，Anki 不会自动认作重复。第十天与第十一次的乘法卡、第三天两张加法 OF 卡等，按修订说明择一保留或暂停另一张；本次未从用户 Anki 中删除或暂停任何卡。
