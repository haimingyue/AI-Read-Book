## 1. 整数：先定位宽，再定读法

n位无符号整数范围为0～2^n−1；n位补码整数范围为−2^(n−1)～2^(n−1)−1。把同一位串按无符号读为U，若最高位为1，补码真值是U−2^n；最高位为0时为U。补码求负可取反加1并保留n位，但最小负数的正相反数无法在原宽补码内表示。[Cornell数值表示讲义](https://www.cs.cornell.edu/courses/cs3410/2025sp/notes/numbers.html)

### CF与OF

下面CF采用题目常见的“减法借位为1”约定；不同体系结构的标志定义可能不同，先查题设，不能把任何减法器的最高进位直接命名为CF。

- **加法CF**：两个无符号n位值的精确和超过2^n−1。
- **减法CF**：无符号被减数小于减数。用A+取反B+1实现时，借位与最终加法进位互补。
- **OF**：补码有符号运算的精确结果超出n位范围。结果存低n位并不表示没有溢出。
- **符号判据**：加法仅两个操作数同号时可能溢出，此时结果符号反转；减法仅两个操作数异号时可能溢出，此时结果符号异于被减数。

例：`120−(−20)=140`。

| 位宽 | −20的位串 / 无符号值 | CF | OF及原因 |
|---|---|---|---|
| 8位 | ECH / 236 | 1 | 1；140>127 |
| 32位 | FFFFFFECH / 4294967276 | 1 | 0；140在32位补码范围内 |

两个负数相减也可能借位：8位−120−(−20)对应无符号136−236，CF=1；−5−(−9)对应251−247，CF=0。加减标志可参照[C-Jump课程讲义](https://www.c-jump.com/CIS77/CPU/Overflow/lecture.html)的实例，再按题设位宽验算。

**语境边界**：以上讨论定宽机器运算。题目给了类型长度、机器模型或截断假设时按题设算；真实C程序还涉及整数提升、转换和有符号溢出的语言规则，不能声称任何C有符号表达式都按低n位回绕。遇到语言语义问题需另查对应标准，不能从硬件示意推断。

## 2. IEEE754单精度：公式带条件

字段为S(1位)、E(8位)、M(23位)；E表示无符号阶码整数，0.M与1.M表示二进制小数。

| 条件 | 真值/含义 |
|---|---|
| 1≤E≤254 | (−1)^S × (1.M)₂ × 2^(E−127) |
| E=0，M非0 | (−1)^S × (0.M)₂ × 2^−126 |
| E=0，M=0 | 按S区分+0、−0 |
| E=255，M=0 | 按S区分+∞、−∞ |
| E=255，M非0 | NaN |

规格化真指数是−126～127，最小规格化正数2^−126，最小非规格化正数2^−149，最大有限正数(2−2^−23)×2^127。E=127时真指数为0；只有再加S=0、M=0才是+1。字段与边界核对自[Oracle数值计算指南](https://docs.oracle.com/cd/E19059-01/stud.10/819-0499/ncg_math.html)。

编码必须区分规范化与非规格化；规格化数写为1.M×2^e后，E=e+127。M不足23位补0；超出需按指定模式舍入，舍入还可能引发指数调整。分母约分后是2的幂是二进制有限表示的必要条件，单精度精确存储还要满足该格式精度和范围。

校验值（存储位串按高位在左写十六进制，不是内存字节排列）：

| 真值 | 单精度位串 |
|---|---|
| +8.25 | 41040000H |
| −8.25 | C1040000H |
| +12.5 | 41480000H |
| +25 | 41C80000H |
| −0.4375 | BEE00000H |
| −2^−128 | 80200000H |

**外部讲义也要反算**：[Cornell浮点页](https://www.cs.cornell.edu/courses/cs3410/2024fa/notes/float.html)的8.25推导可参考，但该页后续代码中的41020000H实际是8.125；不要把代码常量当8.25的答案。

## 3. 乘法：区分算法、完整乘积、截短结果

### 无符号数值部分的移位加法模型

M和Q各n位；P为n位高半，C为额外1位进位。初始P=0、C=0。每轮查看Q最低位：

1. 为1则计算P+M，把n位和存P、额外进位存C；为0则本轮不加，C置0。
2. 将C|P|Q这个2n+1位串整体逻辑右移一位，左端补0。因此原C进入P最高位，P最低位进入Q最高位。
3. 重复n轮，P|Q给出2n位完整乘积。不能省掉“不加”轮的移位。

这是明确选定的算法模型；若教材采用其他寄存器宽度或原码小数记法，按原件重新对应。原码符号与数值部分分开处理，Booth补码算法不套这个判位步骤。

### 截到n位的判据

- 无符号：高n位全0才不溢出。
- 补码有符号：高n位全等于低n位的最高位（低半的符号位），才不溢出。
- 仅说“高半全0或全1”还不够，必须与低半符号一致。

自编核对例：4位7×2完整乘积 `0000|1110`，截成无符号4位能表示14；截成补码4位会溢出，因为其最大正数是7。题内umul/imul分别处理无符号/有符号乘法，函数名不代表“是否溢出”。真题以[2020/截图05](真题/Chapter2_1/2.3_4.jpg)的定义为准。

## 4. Cache：地址单位与容量口径

以下限**常规按低位索引的直接映射、字节编址、B字节/块、C字节数据区**：行数L=C/B；地址A÷B的商是内存块号、余数是块内字节偏移；块号÷L的商是Tag、余数是Cache行号。若B与L为2的幂，地址分为Tag | log₂L位行号 | log₂B位偏移。

- 容量若包括Tag、有效位、脏位等，不能直接用总位数除以数据块大小。
- 按字编址要统一为每块多少字；a路组相联用组数L/a求组号，Tag比较在该组的各路进行。
- 命中需要候选行有效且Tag匹配。局部性提高命中的机会，不保证命中。
- 题目若给特殊映射约定，以原件和对应解析为准。2012/截图30明确依赖解析“注意”，目前须补图。
- 缺失率的分母按题问统计；数组读写、仅读、含取指等不能混用。2016/截图31约为250/2000=12.5%，不能省去读写计数或擅加原题未写的对齐条件。

概念参照[Cornell Cache讲义](https://www.cs.cornell.edu/courses/cs3410/2025fa/notes/caches.html)。其Larger Blocks段有将低b位误写为低b字节的文字问题；分段公式须按单位核查。

## 5. 性能：比较相同工作量的执行时间

CPU时间=动态指令数IC×平均CPI÷主频f；f使用Hz。MIPS=IC/(CPU时间×10^6)=f/(CPI×10^6)。MIPS不限定为整数指令数，也不是跨程序/跨指令集的通用性能排名。

同一任务若指令数不同，只比较CPI/f会漏掉IC。主频提高或CPI下降的单变量结论都需其他量不变。CPU执行时间不等于包含I/O等待的总耗时。自编校验例：IC=4×10^8、CPI=4、f=2GHz，时间=(4×10^8×4)/(2×10^9)=0.8s。进一步见[第1章笔记](伴读笔记/第1章_计算机系统概述.md)。
