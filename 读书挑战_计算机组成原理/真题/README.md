# 真题截图目录

来源：`books/2026计算机组成原理_带书签.pdf`，共348页。2026-10-07从原书提取 **208道** 带年份标记的统考真题（176道选择题、32道综合应用题），按27个教材小节编目。题目图直接截自PDF，跨页部分按阅读顺序拼接；教材解析分开保存。

- **题目**：各章节的 `题目/`，文件名为“年份_类型_教材题号”。
- **教材解析**：各章节的 `解析/`，208题均配套保存；`解析原页/`保留整节原书解析，便于核对注释和裁剪边界。
- **PDF原页**：保留被使用的完整原书页面，便于检查跨页内容、裁剪边界和图表。练习时优先打开题目图，原页可能含相邻题或解析。
- **提取记录**：`提取记录.json`记录每题的PDF页、书页、像素裁剪范围和SHA-256。PDF第13页对应书内第1页，页码偏移为12。
- **核对范围**：[核对记录](核对记录.md)说明检查方法及题号、来源的边界。
- **旧截图**：原有24张JPG保留，用于兼容已有学习日志；当前按本目录的新索引选题。

题号采用本书习题编号，不自行换成全国卷编号。年份来源于本书“统考真题”标记，尚未逐一与官方原卷核验。OCR仅用于定位和索引；截图文字不由AI重写。授课前仍须打开原图核对完整题干、选项、图表及适用条件。
