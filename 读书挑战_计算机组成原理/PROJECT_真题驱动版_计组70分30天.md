# 真题驱动学习方法（当前说明）

> 2026-09-29 修订。保留文件名以兼容旧链接。原“30 天排程”已停用，日期与工作量只看 [主排程](学习排程.md)。目标是计组部分**得分率 70%**，不承诺仅靠选定考点就能达到。

真题用于确定考试任务和检验学习效果。零基础遇到缺失的前置知识时，应先学习必要概念、看示范，再逐步独立做题；教材、课程小节、图示和笔记都可以按需使用。

## 一次学习怎样进行

| 环节 | 具体动作 |
|---|---|
| 1. 确定任务 | 看 [当前状态](状态与下一步.md) 和主排程，选择一个可处理的目标及少量到期复验项 |
| 2. 核对原件 | 打开对应真题原件；找不到就请用户截图保存到对应 `真题/` 文件夹，核对后再做，不凭记忆补题 |
| 3. 检查起点 | 用短问题检查先修知识；已具备基础则先独立尝试，完全不会则先补基础和示范 |
| 4. 练习与反馈 | 记录首次答案；反馈具体错在何处，逐步撤除提示，需要时围绕真实卡点做明确标注的自编练习 |
| 5. 独立验证 | 用新题或新的解释任务检验；会做后及时组合步骤，熟悉题型再限时 |
| 6. 记录与再访 | 区分提示后完成、当场独立、间隔独立与迁移；安排后续复验，按需要记录笔记或制卡 |

具体来源规则、掌握标准、反馈方式及交接要求统一见 [辅导规则.md](辅导规则.md)；制卡见 [笔记与 Anki 规则](03_笔记与Anki使用规则.md)。不在本文件重复保存状态、逐日计划或题号清单。

## 如何判断方法是否有效

- 观察首次无提示表现、之后能否独立再做，以及是否能处理变化后的条件；不把当场纠正后的“全对”记成首次正确率。
- 用已核对原件的限时测验检查实际得分，注明试卷是否见过；高频题做对不直接等于整卷达标。
- 如果连续卡在同一步，检查先修知识和解释方式，调整示范或题目难度，再复验。复习间隔和练习数量随实际表现调整。
