# 考研英语二写作学习

本项目服务于约60天后的考研英语二写作。用户已确认考英语二，尚未做过大小作文完整测试。2026年10月22日为D1。用户已确认每天早上约一小时驾驶语音学习，另每周三次、每次15至20分钟停车后书写，先排周二、周四、周六。每天北京时间07:30准备自带课程内容的文档，课后由用户回传记录更新进度；其他科目的预算不变。D1语音核心及首篇应用文手写稿已回传；10月27日补收了10月23日D02复盘，两条旧表达已有一次隔天口头提取成功。当前下一实际课程为D03，优先修祝贺连接与理由句；书面修订、大作文及关键结构的独立迁移仍待验证。

规划用冲刺目标暂设为大小作文合计20分左右，基础和进步允许时再争取更高分。该目标尚待诊断校准，不是成绩承诺。书中英语二写作分值为小作文10分、大作文15分；教学暂按小作文约100词、大作文约150词准备，练习时始终服从具体题目的要求。当届大纲需另行核对，不把2025版教材当作当届大纲。

## 从这里开始

1. 阅读[语音训练流程](语音训练流程.md)与[辅导规则](辅导规则.md)，了解每日文档、驾驶模式、停车后书写和回传方式。
2. 阅读[状态与下一步](状态与下一步.md)，确定下一次实际学习任务。
3. 从[学习排程](学习排程.md)领取当天任务，这是唯一排程。
4. 用[教材拆分与学习方法](教材拆分与学习方法.md)查原书页码、材料用途和复习方法。
5. 学习结束后把真实作答、提示和复测证据写入[进度日志](进度日志.md)。

教材为[新东方2025考研英语高分写作](../books/新东方%20%282025%29%20考研英语高分写作.pdf)，王江涛编著。PDF共265页，正文印刷页码1至250；正文的PDF顺序页等于印刷页码加15。学习主线为第一章、第二章和第四章。

## 怎样判断有效

看陌生题目能否独立完成任务，观察要点、逻辑、语言准确性、数据和用时。看懂范文、照着改对、默写原文和独立写新题分别记录。整篇背诵只在有明确用途时选用，日常重点是理解篇章功能、提取少量表达并用于不同题目。

D1已绑定2026年10月22日，确切考试日仍待确认。当前计划为每天语音上限60分钟，加每周三次书写；按约8至9周估算共预留约66至69小时，实际听课、暂停和减量另记。第7、21、35、49课补漏，末尾4课减量；若可用天数不足，先削减预测和拓展任务，保护反馈、复测。
