# AI Read Book

计算机组成原理自学与AI辅导工作区。当前目标为408计组部分得分率达到70%，每天计划约1小时，阶段验收日为2026年10月26日。

从[学习入口](读书挑战_计算机组成原理/README.md)开始，依次阅读辅导规则和当前状态。日期只按[学习排程](读书挑战_计算机组成原理/学习排程.md)执行；实际进度由作答记录决定。

- `读书挑战_计算机组成原理/`：学习规则、进度、错题、真题截图、笔记与Anki CSV。
- `books/`：教材及补充阅读；教材PDF通过Git LFS存储。
- `AGENTS.md`：AI接手本工作区的要求。

## 获取文件

先安装Git LFS，再克隆：

```bash
git lfs install
git clone https://github.com/haimingyue/AI-Read-Book.git
cd AI-Read-Book
git lfs pull
```

历史归档保留旧错误与废弃计划，只用于追溯。更新本地Anki CSV不代表Anki已同步。
