# AI Read Book

计算机组成原理与数据结构自学及AI辅导工作区。2026年10月7日用户确认两科并行，每天共约2小时、两科各60分钟。计组目标仍为该部分得分率达到70%，阶段验收日为2026年10月26日；数据结构目标得分率另行确认。

计组从[计组学习入口](读书挑战_计算机组成原理/README.md)开始，数据结构从[数据结构学习入口](读书挑战_数据结构/README.md)开始，分别阅读辅导规则与当前状态。两科各自维护唯一排程；实际进度由作答记录决定。

- `读书挑战_计算机组成原理/`：学习规则、进度、错题、真题截图、笔记与Anki CSV。
- `读书挑战_数据结构/`：8章核心知识地图、教材真题索引、每日计划、辅导规则与学习证据。
- `books/`：教材及补充阅读；教材PDF通过Git LFS存储。
- `AGENTS.md`：AI接手本工作区的要求。

## 获取文件

先安装Git LFS，再克隆：

```bash
git lfs install
git clone https://github.com/haimingyue/AI-Read-Book.git
cd AI-Read-Book
git lfs pull
```

历史归档保留旧错误与废弃计划，只用于追溯。更新本地Anki CSV不代表Anki已同步。
