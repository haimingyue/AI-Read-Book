# AI Read Book

计算机组成原理、数据结构与计算机网络自学及AI辅导工作区。2026年10月7日用户确认计组与数据结构并行，每天共约2小时、两科各60分钟；计算机网络指定从11月1日开始，其每日时长和11月起总预算待确认。计组目标仍为该部分得分率达到70%，阶段验收日为10月26日；数据结构与网络的目标得分率另行确认。

按科目进入[计组](读书挑战_计算机组成原理/README.md)、[数据结构](读书挑战_数据结构/README.md)或[计算机网络](读书挑战_计算机网络/README.md)，分别阅读辅导规则与当前状态。各科维护唯一排程；实际进度由作答记录决定。

- `读书挑战_计算机组成原理/`：学习规则、进度、错题、真题截图、笔记与Anki CSV。
- `读书挑战_数据结构/`：8章核心知识地图、教材真题索引、每日计划、辅导规则与学习证据。
- `读书挑战_计算机网络/`：6章核心知识地图、教材真题索引、11月1日起的每日计划与学习证据。
- `books/`：教材及补充阅读；教材PDF通过Git LFS存储。
- `AGENTS.md`：AI接手本工作区的要求。

## 获取文件

先安装Git LFS，再克隆：

```bash
git lfs install
git clone https://github.com/haimingyue/AI-Read-Book.git
cd AI-Read-Book
git lfs pull
```

历史归档保留旧错误与废弃计划，只用于追溯。更新本地Anki CSV不代表Anki已同步。
