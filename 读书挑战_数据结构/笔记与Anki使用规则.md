# 数据结构笔记与Anki使用规则

沿用计组的少而精原则，每次通常0～3张，不凑数。先理解，再根据实际遗忘或混淆选卡；完整算法和长计算继续用完整题检验。

| 内容 | 建议记录方式 |
|---|---|
| 易混定义、适用条件 | 一问一答或短辨析，写明条件 |
| 指针修改、递归返回、算法关键决策 | 小图或短步骤，解释为何如此 |
| 完整算法题 | 思路、关键代码、边界、复杂度及实际错因 |
| 树图手算、排序过程 | 完整练习；卡片只保留关键规则 |

一张卡只检验一个主要目标，KMP、队列、树高等必须写明约定。已有卡能覆盖时优先修订，避免重复。旧卡由用户在Anki中自行复习，除非用户要求，不在对话里代刷。
