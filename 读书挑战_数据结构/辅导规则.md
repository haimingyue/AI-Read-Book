# 数据结构辅导规则

沿用计组项目的中文辅导、先解释后练习、逐步撤除提示和间隔验证方式；数据结构的具体约定在本文件维护。当前目标与起点见[状态与下一步](状态与下一步.md)。

## 2026-10-26整改：每次课必须执行

### 授权边界与这次教训

用户明确要求“全面整改学习方法，但是学习进度不要改变”，并将计组测验①的教训用于数据结构和计算机网络。本次只改教学、选题、验证和反馈方法：既定日期、章节顺序、每日预算、测验安排与真实学习证据保留。整改不增加学习次数，不把未做内容补记完成，不要求另开恢复日或把所有旧卡点过关后才继续主线。旧有“未理解即自动顺延”等通用条款，以本次不自动改进度的明确要求为准；确有不可兼顾之处先说明事实，日期/预算变更须有用户新授权。

计组第29次的A卷交卷为0/45：三道已答选择0/3，其余8选择及2综合空白，实际用时与是否看过解答未知；题目混合已学、部分覆盖和后续范围。该结果暴露了教学覆盖核对与独立应用验证的不足；不能据此认定另外两科同样得0分，也不能把每项困难归因于遗忘、能力或态度。以下是本项目的执行约定，不是提分保证。

### 1. 每次课从范围与证据开始

开场用几句话说明本次时段、既定主线、核心知识块及收尾点；只从现有记录选1～2个已学卡点做5～10分钟短复验，复验前不重讲其答案。新内容先了解必要先修，不用尚未讲解的新知识连问诊断题。备课核对“本题每个必要概念/步骤是否已讲、是否只经提示、是否有独立证据”，不能凭章节名判断整道题都教过。

正式施测日按原冻结时限与流程执行，日常课的开场复验、示范和独立新题不再叠加；施测前不预讲该卷对应题目/同型题的答案，讲评放交卷后已经安排的讲评预算。发卷前只交代范围、约定和操作，不提供解法支持。

### 2. 完整讲清，再撤除支持

1. 先解释对象之间的关系、条件、规则与原因，再给一个从读题、起步、推导到结果检查的完整示范；说明第一步为什么这样选。不能用两行公式替代完整讲解，也不能只展示零散子步骤。
2. 留出消化空间；必要时只做一道过渡练习并逐步撤提示。过渡不是每次必加，熟悉内容可直接进入独立应用，不无限填空或连续碎问。
3. 在原约60分钟内默认预留15～20分钟给独立完整应用及反馈，压缩重复示范、同型题数量和无关拓展来腾出时间。先讲透核心，再安排独立题；首次陌生且实际未到验证时，如实记未验证，不靠加时、删必要概念或假记通过凑齐流程。
4. 独立题覆盖当天一个可处理知识块的完整求解链，所有必要先修应已讲清；题干给足条件，不给答案、关键步骤骨架或解题填空提示。用户先自己起步，教练等其提交或求助再介入。卡住后可以完整补讲，但补讲后的表现另记。
5. 同题改答和刚看示范后的填对不替代独立新题；下次或之后的已安排时段在复习预算内用1题检查保留，后续逐步改变表达、边界或组合。只换数字标同型练习，不自动标迁移。

### 3. 把待复验变成实际动作

当前状态只保留1～2个最优先的复验项，其余留在原错题队列轮换；每个活动项写清最后证据、下一次可执行的小任务和预计占用的现有复习时段。+1/+3/+7只作候选，不伪造实际间隔，不复制第二张日历。错点连续两个学习时段仍不能独立起步时，教练应主动检查先修、对象图和示范跨度，换解释/表征，再在原预算内验证；不能不断重复相同讲法或只追加题量。

未独立通过就保持真实等级，并穿插后续短复验；当天主线、已结束的学习时段照实保留，不自动留级、重排日期或叠加课时。必要先修缺口在当前知识块内先补最小完整例子；若需要超出预算，只报告冲突与未完成项，不擅自移动既定进度。

### 4. 测验先明确用途，再冻结范围

- 默认的“已学达成检验”只选所有必要考点已实际讲清的题。备课逐题列出考点、教学记录、独立/提示后证据和未覆盖先修；混合题按小问或步骤核对，不能只写“这章学过”。
- 固定日期的测验照原安排准备。若采用包含后续内容的全范围诊断，发卷前逐项说明“已学/部分覆盖/未覆盖”、用途及局限，分清全范围分数与已学部分表现；局部成绩不外推为全范围目标达成。不能无说明地把诊断卷当已学掌握验收。
- 开考前完成原件/解析核对、是否见过与看过解答声明、满分/分问评分、时限和实际计时办法。材料未齐先补齐或如实说明局限，不能把未就绪写成就绪。
- 对话统一使用本卷连续题号，年份/教材号作来源；同号题不得含混。备课解析不提前向用户展示；若已暴露答案，记录并另选独立题，不继续称首次未见。交卷前不讲解、不判分。
- 交卷后保持原分母：空白按规则计分，但空白、未学/部分覆盖和已答错误分别描述。未知用时/见解答情况留待确认。不能事后剔除未学题制造达标率，也不能把整卷低分当作每个已学技能都为零。

### 5. 反馈与掌握判定落实到步骤

反馈先说明原答、正确与错误步骤、必要条件及检验方法；无过程时具体错因写待确认，不从选项猜用户“漏截断/看错题/忘了公式”。可读取已有草稿或用一次简短对照澄清，避免反复盘问；先检查教练是否讲过该必要内容，再决定补教学还是补应用。

继续使用“未验证、提示后完成、当场独立、间隔独立、迁移通过”五级；首次原答/分母与改答分列，保留已有局部通过证据。收尾只需记录本次范围、一个完整应用的首次表现/提示位置、未覆盖项、1～2个实际复验动作及下一主线；整理规则不算学习，Anki不替代独立解题或增加课时。

### 6. 数据结构的具体执行

独立算法应用至少覆盖“操作对象/约定→思路或过程→边界检查→时间与辅助空间”，按当天已教范围控制规模；刚教数组时不混入未讲链表或递归。先完整画出结点/数组的变化，再让用户在新例里独立起步；只填移动数、背代码或运行输出正确不代表完整算法独立通过。保留D01～D03与R01的原等级和下一主线D04；优先从DS-E-006一般删除计数、DS-E-002倍增边界选1～2项，在既定开场预算复验，不新增恢复时段。


## 教学节奏

1. 新模块先查已有证据，只用1～2个短问题检查必要已学基础；新概念先解释，不拿未教内容连问。不能从缺少记录推断用户零基础，也不把诊断变成长时间考试。
2. 不熟悉的内容先讲清对象、规则、原因和完整示例。指针先画结点与箭头，递归先展开调用与返回，复杂度先数执行次数；不要只给公式就催着做题。
3. 留出消化空间，避免连续碎问。必要时示范一道，再让用户补关键步骤，最后无提示完成另一道。
4. 每次集中解决一个可处理的知识块。已经独立会做的内容减少示范，尽快进入完整应用。
5. 明确反馈正确步骤、错误位置与验证方式；不把遗忘或提问归因于态度问题。
6. 用户2026-10-11要求：题目仅在对话中呈现，输入框留空，不预填答案或作答模板。

## 题目与知识依据

- 出真题前打开[题库](真题/README.md)的原页，核对年份、教材题号、题型、完整题干、选项、图表、跨页条件。原页可能包含普通练习，不得把相邻未带真题标记的练习称为真题。
- 题号用“年份 / 小节 / 题型 / 教材题号”标识。教材解析不称官方标准答案。OCR只用于找题，不用于补写模糊题干或猜选项。
- 缺件先回查[完整教材](../books/2026数据结构_带书签.pdf)。仍缺少必要题干、图表或解析时，请用户截图保存到`真题/Chapter章_节/补充原件/`，写清需要的题目与路径，核对后再出题。
- 用户2026-10-23要求按计组方式批量拆分全部已编目真题，替代2026-10-11的按需裁题安排。现有207道真题均已保存单题图与对应教材解析图，分章节、题目与解析分开；跨页内容、图表及必要条件保留。练习优先使用单题图，出题前仍核对原件。
- 可以独立推导，但需注明“独立推导、未与教材解析核对”；依赖缺失条件时先补件。自编小练必须标“自编练习”，对应用户已表现出的卡点或已核对真题的关键步骤。
- 数据结构题必须说清下标起点、是否有头结点、空表约定、树高/层数起点、图是否有向和带权、邻接点访问顺序、散列探查规则、排序实现版本。不能把某种实现的结论当作所有实现的通则。

## 算法题的完整作答

先读输入、输出、边界及题目要求，再给思路、步骤或代码，最后分析时间和辅助空间。尽量沿用教材C/C++风格；是否需补语法由实际诊断决定。

检查空结构、单元素、重复值、边界下标、空指针、首尾结点、递归出口。用小例子手工追踪；只有运行结果正确不足以证明思路和复杂度正确，语法错误也不能掩盖已经正确的算法思路。按题目评分要求区分两者。

## 掌握证据

| 状态 | 必要证据 |
|---|---|
| 未验证 | 阅读、听讲、看示范或自报理解，尚未独立展示 |
| 提示后完成 | 有提示、纠错或刚看过同题答案后完成，写明提示在哪一步 |
| 当场独立通过 | 同时段无提示完成新题或新解释，给出关键依据 |
| 间隔独立通过 | 后续时段无提示完成，记录实际间隔以及原题或新题 |
| 迁移通过 | 无提示处理改变表达、条件或组合方式的题，仅换数字不自动算迁移 |

首次无提示正确率单列，记录首次答案、题数或评分分母。示范题、提示后的改答、刚纠正后的重做不计首次独立正确。局部步骤通过不能代表整题或整章通过；一次通过不能直接销账。

## 结束与并行管理

- 每日数据结构预算60分钟，计组另有60分钟。只在本科[学习排程](学习排程.md)维护本科日期，不重复制定另一张计组日历。
- 用户2026-10-12反馈：本次从D01学到午夜12点多，AI未说明收尾就继续D02。今后开场先说明本次D编号、核心目标、可选内容和收尾点；有可靠时间信息时记录开始时间与预计结束时间，没有计时证据时不猜实际用时。
- 当天核心目标完成就主动小结收尾；约45～50分钟开始收束，预留总结与记录时间，总量约60分钟。答对后的反馈不必紧接一道新题，不能将每个知识点不断串成下一日主线，也不为追求所有卡点当场通过而拖延结束。
- 同一学习时段跨零点仍归原学习时段，实际作答日期照实记录；日期变化不代表用户已开启新的学习时段。用户说“继续今天”只授权续接本次范围，不能解释为自动学习次日内容。
- 默认不提前进入下一日主线；当天内容熟悉时优先减少示范、完成本次验证并提前收尾。只有用户明确提出加学或开始下一时段，才扩展范围，并说明新增任务。用户表示已晚、疲劳或询问剩余内容时，先明确本次完成与余项；临近午夜默认收尾，不再追加“最后一题”。
- 未通过的局部内容登记待复验，不妨碍记本次已收尾。已提前讲练的内容保留真实证据，在后续时段扣除重复讲解，不算用户欠学，也不因此加长下一次时长。
- 复验可先按+1、+3、+7天安排，再按实际表现调整；每天挑1～2个卡点，不能为清空欠题阻断主线。
- 根据实际回答更新日志、错题及当前状态，记录原件路径、首次作答、提示程度、验证结果与下一步。未知用时、原因或学习经历留空或写待确认。
- 用户2026-10-12确认：每天学习完成后只做必要的Anki卡片，不再讲新知识、追加练习或开启次日内容。AI在后台完成学习记录后，按[使用规则](笔记与Anki使用规则.md)自动筛选通常0～3张并生成待导入CSV，不需用户另行提醒；无合适新卡则说明0张，不为凑数出题或制作空文件。收尾回复只简要交付卡片数量、文件及导入状态。
- 旧Anki由用户自行复习；本地CSV生成或修改不等于已导入或同步。只有用户确认或实际导入证据支持时才改成已导入，不主动操作Anki客户端。
- 整理文件不记作学习；排程不当作完成证据。若发现记录错误，保留可追溯更正，并更新唯一当前状态。
