# 数据结构唯一执行排程

2026-10-07建立。用户确认每天共约2小时，计组与数据结构各60分钟。计组继续执行[原有日历](../读书挑战_计算机组成原理/学习排程.md)，本科初始计划从10月7日到11月20日，共45个时段。此日期范围是可调整的学习估算，不是用户确认的考试日期或达标期限。

## 每日时间预算

| 部分 | 计划时间 | 用途 |
|---|---|---|
| 到期复验 | 5～10分钟 | 1～2个真实卡点；首日改为起点诊断 |
| 新知识与示范 | 20～25分钟 | 讲清对象、原因、条件与一个完整示例 |
| 练习与独立验证 | 20～25分钟 | 一道完整题或数个关键步骤，逐步撤提示 |
| 收尾 | 5分钟 | 记录实际表现、错因和下一步 |

各段弹性分配，总量约60分钟；不把各段上限同时相加。已经会的内容压缩示范、增加新题；完全陌生时允许本日集中讲解，不造独立成绩。

## 复习与取舍

- 学习后按表现暂排+1、+3、+7天的短复验，具体日期写错题本，不复制另一张每日主日历。当天只选1～2项，不集中偿还全部欠题。
- D08、D20、D30、D37、D42含诊断和补缺空间；不能把同一时段同时算新增内容和额外备用时间。
- 未理解时先保留必要基础，把后续任务顺延；不通过压缩解释、跳过独立验证或延长每日时长来制造完成率。
- 若当天只有较少时间，优先完成一个明确知识块并记录余项。只有用户明确表示未学习时才记未执行，无记录时先保留未知。
- 10月26日复盘两科并行是否可持续。计组阶段验收后的安排由计组项目另行确认；不默认其60分钟自动转给数据结构。
- 11月12日D37前后核对测验材料。可选未见过且来源完整的数据结构部分试题，题干、图表与评分依据必须齐全；题库按章节编排，不等于已备好完整未见试卷。
- 11月19日D44测验时限由所选题目确定，总时段约60分钟；若题量超出，提前调整为分次测验。局部诊断不能称整套408模拟，见过题也不能充当首次无提示成绩。
- 11月20日D45报告真实覆盖与成绩，再修订后续日历；不因到期宣布结课或达到尚未约定的分数。
