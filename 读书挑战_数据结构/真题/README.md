- **题目**：各小节的 `题目/` 文件夹，共207张，命名为“年份_类型_题号.png”。
- **教材解析**：各小节的 `解析/` 文件夹，共207张，与题目逐一对应；跨页代码、图表和说明按原页顺序保留。
- **PDF原页**：原有271张完整来源图片继续保留；各节目录仍提供整节解析与题区原页链接。
- **提取记录**：[提取记录.json](提取记录.json)记录题目编号、页码、裁剪矩形、拼接位置及SHA-256，支持回查和重建。
- **核对范围**：[核对记录.md](核对记录.md)。题号采用教材习题编号，解析为教材解析，不称官方标准答案。

图片直接使用来源原页的像素，未改写题干、公式或图表。练习先打开单题图片，再查看解析；授课前仍核对原件。统计范围是本教材已识别并编目的条目，不代表历年官方试卷完整覆盖。
