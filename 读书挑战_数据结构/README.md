# 408 数据结构自学项目

依据本工作区计组挑战的辅导方式建立，教材为[2026数据结构](../books/2026数据结构_带书签.pdf)。本项目负责数据结构的知识地图、真题、学习证据与每日安排。

2026-10-07用户确认与计组并行，每天共约2小时，两科各60分钟。计组继续执行原定10月26日阶段验收；数据结构先建立基础并完成分阶段诊断，尚未约定目标得分率或正式考试日期。不能把计组70%的目标自动套到数据结构或整个408。

教材共412个PDF页，正文书页1对应PDF第13页；正文定位使用“书页 / PDF页”双页码。真题库只把教材明确带“统考真题”年份标记的条目列为真题，教材习题编号不能当成全国统考原卷题号。每次授课前重新打开原件核对条件。

本次建立目录和整理资料不算学习次数。未知起点记为“待诊断”，无作答记录不等于从未学习。进度按实际证据更新，日期到达不代表任务完成。
