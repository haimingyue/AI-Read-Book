# 408 数据结构自学项目

依据本工作区计组挑战的辅导方式建立，教材为[2026数据结构](../books/2026数据结构_带书签.pdf)。本项目负责数据结构的知识地图、真题、学习证据与每日安排。

2026-10-07用户确认与计组并行，每天共约2小时，两科各60分钟。计组日期以[其独立日历](../读书挑战_计算机组成原理/学习排程.md)为准；数据结构先建立基础并完成分阶段诊断，尚未约定目标得分率或正式考试日期。不能把计组70%的目标自动套到数据结构或整个408。

每次开场说明本次学习时段编号、核心目标与收尾点。当天核心任务完成或接近60分钟时主动收尾；同一时段跨过零点仍属于原学习时段，不能因日期变化自动进入次日任务。次日内容默认留到用户下次主动开始学习，具体执行边界见[辅导规则](辅导规则.md)。

每天学习收尾后只整理必要的Anki新卡并交付待导入CSV，通常0～3张；不追加教学或练习。筛选、格式和导入登记统一按[笔记与Anki使用规则](笔记与Anki使用规则.md)执行。

2026-10-26已按用户要求整改学习方法，具体执行见[辅导规则](辅导规则.md)：完整示范后落实独立新题与后续短复验，出卷前逐题核对实际教学覆盖。本次整改保留日期、章节顺序、每日预算、已有进度与成绩；不能自动增加恢复日或凭听懂提升掌握等级。
