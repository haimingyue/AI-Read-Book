# 数据结构学习范围与优先级

采用“概念和表示 → 基本操作 → 手算过程 → 算法设计 → 间隔迁移”的顺序。教材8章均在计划范围内，先修关系决定先后；不以未经核验的所谓高频比例承诺得分。

| 层级 | 内容 | 训练重点 |
|---|---|---|
| 先修 | 数组、循环、指针、结构体、递归，复杂度 | 能读懂题目中的短程序；缺哪项补哪项 |
| 第一阶段主线 | 顺序表与链表、栈队列、树与二叉树 | 画状态、维护指针、写基本算法；矩阵与串穿插推进 |
| 第二阶段主线 | 图、查找、排序 | 掌握条件、手工执行算法、解释过程与复杂度 |
| 持续练习 | 数组/链表算法、树遍历与递归、复杂度 | 每隔数天在新题里调用旧技能，而不是学完即停 |
| 按诊断控制深度 | 红黑树复杂调整、复杂删除、外排细节等 | 先理解教材范围的基本规则；暂缓深入时明确保留覆盖缺口 |

## 每个知识块的练题路径

先读[知识地图](核心知识地图.md)的一行和教材对应小节；若陌生，老师完整示范一个例子。随后选一题理解概念或基本操作，再选一题要求解释过程或写算法。题目从[分节题库](真题/README.md)选，授课前逐题核对，不按“有题库就要一天刷完一节”执行。

真题不够匹配起点时可以用明确标识的教材普通练习或自编小练；自编只解决已明确的卡点，不冒充真题。安排间隔新题检验，原题复做与新题迁移分开记录。

## 算法题的三个层次

1. 能追踪：给出输入，能画出每步下标、指针、栈队列或树图的变化。
2. 能构造：能说出为什么采用该结构，写出思路和关键步骤，处理边界。
3. 能完整作答：无提示写出符合题意的算法，解释正确性和时间、空间复杂度；以后再用新题检验。

三层分别记录，不把看懂代码当作会独立写代码。尚未掌握语法时可以先写准确伪代码，但若真题要求C/C++，最终还要回到题目要求验证。
