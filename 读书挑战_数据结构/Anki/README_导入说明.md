## 导入参考（仅导入待导入文件）

1. 在Anki导入本次CSV，选择基础/Basic笔记类型，将两列映射为正面与背面；目标牌组可选择自己的数据结构牌组。
2. 文件为UTF-8、逗号分隔、纯文本，前三行依次为separator、html、columns元数据。导入预览应为两列，卡片数以所选文件为准（R01为1张，D02为2张）；元数据不是卡片；关闭HTML解释，保留代码中的小于号与大于等于号。
3. 检查中文、正反面和新增数量，确认没有已有重复卡后导入。旧版本若不识别元数据，可使用去掉前三行的临时副本并手动选择逗号分隔；不要修改唯一源文件。
4. 用户确认导入后再登记已导入，文件可按计组惯例添加`_imported`后缀。只生成CSV不代表已导入或云端同步。
